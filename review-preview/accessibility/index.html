Accessibility information

Our approach

The site uses semantic headings, labelled form fields, visible keyboard focus, a skip link, responsive layouts and reduced-motion support. The aim is WCAG 2.2 AA, without claiming certification or a complete independent audit.

Using the site

Navigation and controls can be used with a keyboard. The mobile menu closes with Escape. Tools display numeric results in text. Resources are available without creating an account. Browser zoom and system font settings are respected.

Known limits

External form and checkout services require their own accessibility testing before launch. Full screen-reader, cross-browser and assistive-technology testing remains part of release review. The studio contact route will be activated before public launch.
